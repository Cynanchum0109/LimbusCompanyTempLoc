# LimbusCompanyTempLoc
Limbus Company Temporary Chinese Localization release by Cynan

仅限 PC 端，需先安装零协翻译后再装本补丁；零协更新后会自动覆盖本补丁。

## 下载

去 [Releases](../../releases/latest) 下载最新的补丁包（zip）。

## 安装

1. 解压后双击 `install.bat`（或右键 `install.ps1` → 用 PowerShell 运行）。
2. 脚本自动查找 Steam 里的 Limbus Company 安装目录并安装；
   若自动查找失败，会提示手动输入游戏安装路径
   （形如 `D:\Steam\steamapps\common\Limbus Company`）。
3. 若脚本都失败，把压缩包内的 `LLC_zh-CN` 文件夹复制到
   `Limbus Company\LimbusCompany_Data\Lang`（Steam 右键 Limbus Company → 管理 → 浏览本地文件，
   导航到里面有 `LLC_zh-CN` 文件夹的那一层即为正确目录），选择替换所有文件。
4. 安装完成后重启游戏。
